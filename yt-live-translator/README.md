# مترجم يوتيوب الفوري (تركي ← عربي)

إضافة لمتصفح Chrome / Edge / Brave تلتقط صوت تبويب يوتيوب وتترجمه **لايف** إلى العربية، وتعرض الترجمة فوق الفيديو (تعمل حتى في وضع ملء الشاشة).

## كيف تعمل

```
صوت التبويب ──► Deepgram (تحويل الكلام التركي إلى نص، مباشر)
            ──► Claude (ترجمة سينمائية مع سياق آخر 6 جمل + أسماء الشخصيات)
            ──► ترجمة عربية فوق الفيديو
```

سبب جودة الترجمة: النموذج يتعامل مع النص كحوار مسلسل (لا كلمة بكلمة)، يصحّح أخطاء التعرّف على الصوت من السياق، ويثبّت أسماء الشخصيات.

## التثبيت

1. حمّل مجلد `yt-live-translator` على جهازك.
2. افتح `chrome://extensions` وفعّل **وضع المطوّر (Developer mode)**.
3. اضغط **Load unpacked** واختر المجلد.
4. ثبّت الإضافة في شريط الأدوات.

## المفاتيح المطلوبة (مرة واحدة)

- **Deepgram** (تحويل الصوت إلى نص): https://console.deepgram.com — أنشئ API Key.
- **Anthropic** (الترجمة): https://console.anthropic.com — أنشئ API Key.

المفاتيح تُحفظ محليًا في المتصفح فقط وتُرسل مباشرة للخدمتين دون أي سيرفر وسيط. الاستخدام مدفوع حسب الدقائق/الاستهلاك، راجع الأسعار الحالية لدى الخدمتين.

## الاستخدام

1. افتح الحلقة في يوتيوب وشغّلها.
2. اضغط أيقونة الإضافة ← **ابدأ الترجمة على هذا التبويب**.
3. تظهر الترجمة بعد ثانية إلى ثلاث ثوانٍ من نطق الجملة (هذا التأخير طبيعي في أي ترجمة لايف).

نصائح للجودة:
- اكتب أسماء الشخصيات في خانة «أسماء الشخصيات» بصيغة `Kerem=كيريم`.
- اختر الأسلوب: فصحى مبسّطة، شامية خفيفة، أو بيضاء.
- فعّل «إظهار النص التركي» إن أردت مقارنة الترجمة بالأصل.
- إن ضعف التعرّف على الصوت بسبب الموسيقى العالية، جرّب نموذج `nova-3` من «متقدّم».

## ملاحظات

- الصوت يستمر بالعمل عاديًا في التبويب أثناء الترجمة.
- لا تعمل على الجوال (التقاط صوت التبويب متاح في متصفحات سطح المكتب فقط).
- الإضافة لا تلمس ترجمات يوتيوب نفسها؛ تعرض طبقة خاصة بها فوق المشغّل.
